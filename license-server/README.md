# Сервер лицензий Lotus

Твой главный сервер. Решает, годен ли код подписки. Клиенты его не видят — их воркеры только спрашивают статус.

## Установка (на твоём VPS)

```bash
cd license-server
sudo bash install.sh
```

Скрипт поставит Docker, создаст админ-токен и запустит сервер. В конце покажет **адрес для воркеров** вида `http://IP:8900` — это значение `KASSA_LICENSE_URL`.

## Подключить воркеры клиентов к серверу лицензий

В сборку клиента адрес лицензий попадает так: при установке воркера задаётся переменная `KASSA_LICENSE_URL`. Проще всего — прописать её в команде установки, которую ты даёшь клиентам:

```bash
KASSA_LICENSE_URL=http://ТВОЙ_IP:8900 KASSA_REPO=https://github.com/robinhilk488-bot/Lotus.git bash <(curl -s https://raw.githubusercontent.com/robinhilk488-bot/Lotus/main/install.sh)
```

Если `KASSA_LICENSE_URL` пустой — воркер работает без подписки (режим «для себя»).

## Коды подписки

```bash
./manage.sh gen 1 50     # 50 кодов на 1 месяц
./manage.sh gen 3 20     # 20 кодов на 3 месяца
./manage.sh gen 6 20
./manage.sh gen 12 10
./manage.sh stock        # сколько свободных кодов осталось
./manage.sh servers      # клиенты и их статус
```

Сгенерированные коды (формат `KSA-XXXX-XXXX-XXXX`) загрузи в **автовыдачу** своих лотов подписки на FunPay (раздел «Автовыдача» → режим «Из списка»). Покупатель оплатит лот, получит код в чат и введёт его в разделе «Подписка».

## Правила

- Код активируется один раз и навсегда привязывается к серверу клиента. Переезд на другой хост — код не переносится.
- Продление суммируется: осталось 10 дней + код на 30 → 40 дней.
- Первый запуск воркера даёт клиенту **пробный период 3 дня**.
- Подписка кончилась → плагины не берут новые заказы, но дорабатывают начатые. Всё остальное (бот, чаты, продажи, автовыдача, аренда) работает всегда.
- Если сервер лицензий недоступен, у оплатившего клиента подписка действует ещё 3 дня, пока связь не восстановится.
