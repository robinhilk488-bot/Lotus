# Lotus

Lotus — помощник для продавцов FunPay. Автоматизирует рутину и работает на вашем сервере круглосуточно.

## Возможности

- **Автовыдача** — товар уходит покупателю сразу после оплаты: общий текст или уникальная строка из списка.
- **Чаты и автоответы** — переписка со всеми аккаунтами в одном окне, приветствие, вызов продавца командой, «спасибо» за отзыв.
- **Автоподнятие лотов** — по расписанию.
- **Статистика** — выручка, чистая прибыль с учётом комиссии и себестоимости, лучшие лоты.
- **Уведомления в Telegram** — о заказах, отзывах и проблемах.
- **Плагины** — AutoSMM, аренда Steam-аккаунтов и другие.

## Как устроено

- Сервер работает на вашем VPS 24/7: принимает заказы и выдаёт товар.
- Приложение на ПК — пульт управления, его можно закрыть, продажи не остановятся.
- Связь шифруется, golden_key хранится только на вашем сервере в зашифрованном виде.

## Подписка

Базовые функции бесплатны. Плагины работают по подписке: 3 дня бесплатно, затем активация кода.
