# Lotus

Lotus — помощник для продавцов FunPay. Автоматизирует рутину: выдачу товара после оплаты, ответы покупателям, поднятие лотов, аренду аккаунтов, статистику и плагины.

Две части:

- **worker/** — сервер. Работает 24/7 на VPS в Docker: хранит аккаунты, собирает продажи, запускает плагины.
- **client/** — приложение для ПК. Это пульт управления: его можно закрыть, сервер продолжит работать.

Связь между ними шифруется (HTTPS), приложение проверяет отпечаток сертификата сервера и токен из ключа подключения. golden_key хранится только на сервере в зашифрованном виде.

## Как получить Lotus.exe

1. Создайте на GitHub **публичный** репозиторий. Публичный нужен, чтобы сервер мог скачать установщик. Секретов в коде нет: ключи хранятся только на вашем сервере.
2. Загрузите в него все файлы проекта, включая скрытую папку `.github` (Add file → Upload files, или через GitHub Desktop).
3. GitHub сам соберёт программу за 3–5 минут: вкладка **Actions** → «Сборка Lotus.exe».
4. Готовый файл: вкладка **Releases** → «Последняя версия» → `Lotus.exe`.

После каждого изменения в папке `client/` exe пересобирается автоматически. Адрес репозитория в команду установки подставляется сам.

При первом запуске Windows может показать «Windows защитила ваш компьютер» — так бывает со всеми программами без платной подписи. Нажмите «Подробнее» → «Выполнить в любом случае».

Собрать exe на своём компьютере тоже можно: `client/build.bat` (нужен Python 3.12).

## Первый запуск

Lotus.exe открывается с экраном «Установка сервера»:

1. Подготовьте VPS (Ubuntu 22.04+, от 1 ГБ памяти).
2. Подключитесь к нему: `ssh root@IP-сервера` в PowerShell.
3. Скопируйте команду установки кнопкой «Скопировать» и вставьте в окно сервера.
4. В конце установщик покажет **ключ подключения** `lotus_…`. Вставьте его в поле «Ключ подключения» и нажмите «Войти».

Ключ запоминается. Показать ключ ещё раз или обновить сервер: `bash /opt/kassa/install.sh` на сервере.

Полезные команды на сервере:

```bash
docker logs -f kassa-worker
cd /opt/kassa && docker compose restart
```

## Разделы приложения

- **Сводка** — общий баланс, выручка и чистая прибыль за 30 дней, график, журнал.
- **Чаты** — переписка с покупателями всех аккаунтов, ответ прямо из приложения.
- **Продажи** — выручка, чистая прибыль (минус комиссия и себестоимость), лучшие лоты, таблица заказов.
- **Автовыдача** — лоты и товар: один текст всем или уникальная строка из списка.
- **Автоответы** — приветствие, вызов продавца командой, «спасибо» за отзыв.
- **Плагины** — каталог; у каждого плагина кнопка «Настроить» открывает его полную страницу.
- **Подписка** — активация кода, статус, покупка через FunPay.
- **Аккаунты** — аккаунты FunPay по golden_key.
- **Настройки** — уведомления в Telegram, автоподнятие, чёрный список, комиссия, частота проверок.

## Плагины

- **Автовыдача** — выдача товара после оплаты.
- **AutoSMM** — продажа SMM-услуг через панели со стандартным API v2. Код услуги `#1-1234` в конце описания лота, запрос ссылки, подтверждение, `!status`, два поставщика, лимит цены.
- **Аренда Steam** — аренда аккаунтов: выдача, коды Guard по команде, продление отдельным лотом, смена пароля после аренды.
- Остальные плагины каталога помечены «В разработке» и подключаются по мере готовности.

Ключи API вводятся в настройках плагина и хранятся на сервере в зашифрованном виде. Перед запуском у плагинов есть «Проверить подключение» и «Пробный запуск».

## Подписка

Базовые функции бесплатны. Плагины можно сделать платными через отдельный сервер лицензий (папка `license-server/`, свой README): клиент получает 3 дня пробного периода, затем активирует код, купленный на вашем лоте FunPay. Если сервер лицензий не настроен (`KASSA_LICENSE_URL` пуст), подписка не требуется.

## Что важно знать

- Данные FunPay берутся со страниц сайта. Если FunPay изменит вёрстку, часть функций чинится в `worker/core/funpay.py`.
- Ключ подключения даёт полный доступ к серверу — не публикуйте его.
